# GetSupply

Este repositório contém o app GetSupply em um bundle Git completo.

## Restaurar o projeto

Baixe o arquivo trabalho-de-tech-1.bundle e execute:

    git clone trabalho-de-tech-1.bundle getsupply
    cd getsupply
    git checkout main

O bundle preserva o histórico e os arquivos do workspace, incluindo a aplicação web, o design system, o servidor de API e as bibliotecas compartilhadas.
