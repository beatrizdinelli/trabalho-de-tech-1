# GetSupply

**O que é.** Plataforma B2B que conecta fundadores de marca a fornecedores de embalagem verificados: você descreve o que precisa comprar (RFQ), recebe propostas e compara preço, prazo e MOQ lado a lado antes de decidir.

**Para quem.** Fundador de marca física early-stage (D2C, alimentício, cosmético) comprando embalagem personalizada em lote pequeno ou médio, sem rede de fornecedores própria — não é para comprador industrial de grande volume.

**Como rodar.**
```
npm install
cp .env.example .env   # preencher DATABASE_URL
npm run dev
```
Abre em `http://localhost:5173`.

**O que precisa.**
- `DATABASE_URL` — string de conexão do Postgres (Replit)
- Node 18+
